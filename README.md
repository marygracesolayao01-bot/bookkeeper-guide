## 🚀 Quick Start (in this exact order)

1. **Open the resume template that matches you** (01, 02, or 03).
2. **Replace every `[bracket]`** with your real info.
3. Copy that text into [CVFlow](https://cvflow.co) or [FlowCV](https://flowcv.com) for clean formatting.
4. Run it through [Resume Worded](https://resumeworded.com) for a free score. Fix anything below 70.
5. **Build your LinkedIn About** using template 07. Add a real photo.
6. **Build a portfolio** using outline 05. Use Notion or Carrd. Add a Loom video.
7. **Set up your OLJ.ph profile** using template 08. Get ID-verified.
8. **Apply to your first 10 jobs.** Use cover letter (04) for traditional sites, Upwork proposal (06) for Upwork.
9. **When a client says yes**, send NDA (09) before any access is shared.
10. **Every month with a client**, follow the close checklist (10).

## 🛡️ Pro Tips

- Save TWO versions of your resume: one keyword-heavy for QBO jobs, one for Xero jobs.
- Always run your resume + the job post through [JobScan](https://jobscan.co) before applying.
- Update your OLJ profile every 7 days — it bumps you up in search results.
- Record a 90-second Loom intro video. Attach to every proposal. 3-4x conversion boost.
