# Monthly Close Checklist — Remote Bookkeeper

> Run this every month, in this exact order, for every client.
> Don't deviate. The order matters.

---

## DAY 1 of new month — INTAKE (15 min)
- [ ] Confirm prior month's bank/CC statements are uploaded
- [ ] Ask client for any missing receipts via Slack/email
- [ ] Verify payroll run completed
- [ ] Note any unusual events the client mentioned

## DAY 1-2 — BANK FEEDS (30-60 min)
- [ ] Refresh all bank feeds (QBO or Xero)
- [ ] Review uncategorized transactions
- [ ] Apply bank rules where possible
- [ ] Add to "Ask Client" log (suspense/holding account) anything unclear

## DAY 2-3 — AR & AP (30-45 min)
- [ ] Run AR Aging — follow up on anything 30+ days overdue
- [ ] Run AP Aging — confirm vendor payments scheduled
- [ ] Enter any bills received late from last month
- [ ] Issue/send any pending invoices

## DAY 3 — RECEIPTS & DOCS (15-30 min)
- [ ] Pull receipts from Hubdoc / Dext
- [ ] Match each receipt to a transaction
- [ ] Attach to the corresponding QBO/Xero entry
- [ ] Flag missing receipts in "Ask Client" log

## DAY 4 — PAYROLL (15-30 min)
- [ ] Record payroll journal entry from Gusto/ADP/Paychex report
- [ ] Reconcile payroll clearing account
- [ ] Update 1099 tracking for contractors
- [ ] AU: confirm STP submission

## DAY 4-5 — RECONCILIATION (60-120 min) ⭐ MOST IMPORTANT
- [ ] Reconcile EVERY bank account to $0.00 difference
- [ ] Reconcile EVERY credit card to $0.00 difference
- [ ] Reconcile merchant accounts (Stripe, Square, PayPal, Shopify)
- [ ] Save reconciliation reports to client's Drive folder
- [ ] If any account is off by even $0.01 — STOP and investigate

## DAY 5 — ADJUSTMENTS (15-30 min)
- [ ] Record depreciation (if applicable)
- [ ] Amortize prepaid expenses
- [ ] Record any month-end accruals
- [ ] Verify intercompany / loan accounts

## DAY 5 — TRIAL BALANCE REVIEW (15 min)
- [ ] Run Trial Balance
- [ ] Look for negative balances that shouldn't exist
- [ ] Verify suspense / clearing accounts are at $0
- [ ] Check that AR/AP detail matches the Balance Sheet number

## DAY 6 — REPORTS & SUMMARY (45 min)
- [ ] Run Profit & Loss (compare to prior month + budget if any)
- [ ] Run Balance Sheet
- [ ] Run Cash Flow Statement
- [ ] Run a custom KPI report if client uses one
- [ ] Save all reports as PDFs

## DAY 6 — CLIENT SUMMARY EMAIL (15 min)
- [ ] 1-page summary email:
  - ✅ All reconciliations closed to $0
  - 📊 Revenue: $X · Expenses: $X · Net Profit: $X
  - 📈 vs Last Month: +/- $X / +/- %
  - 🔔 Notable items (1-2 callouts)
  - ❓ "Ask Client" log (anything you need answered)
  - 📅 Next month's deliverable date

## DAY 6 — LOCK & ARCHIVE
- [ ] Set Closing Date in QBO (or Lock Date in Xero)
- [ ] Upload all reports to client's Drive folder
- [ ] Update your time tracker (Toggl/Clockify)
- [ ] Add notes to your client CRM (Karbon / ClickUp / Notion)

---

## MARY'S RULES

1. **Never close a reconciliation unless it's at $0.00.** Investigate every variance, no matter how small.
2. **Never guess at a category.** Use the "Ask Client" account, ask once a month in a batch, never one-off pings.
3. **Always send a summary email even if there's nothing exciting.** Silence kills retention.
4. **Document the variance, the fix, and how to prevent it** the moment you find any error. Future-you will thank present-you.

## SOFTWARE-SPECIFIC NOTES

### QuickBooks Online
- Use `Accountant → Reconcile` view (faster than client view)
- `Accountant Tools → Reclassify Transactions` for batch fixes
- Close the books via `Settings → Account & Settings → Advanced → Closing date`

### Xero
- `Accounting → Reports → Bank Reconciliation Summary`
- Lock dates: `Settings → Advanced → Financial settings → Lock dates`
- Use `Find & Recode` for batch reclassification
